# Credits

cardLib was written by our team and builds on ideas from these projects and authors. Thank you.

| Source | What we learned or used |
|---|---|
| [LemLib](https://github.com/LemLib/LemLib) | Field frame convention, API style, measured omni wheel diameters, documentation layout |
| [EZ-Template](https://github.com/EZ-Robotics/EZ-Template) | Starter project and auton selector ideas, release packaging |
| [OkapiLib](https://github.com/OkapiLib/OkapiLib) | X-drive wheel order and sign conventions |
| [PROS](https://pros.cs.purdue.edu/) | The kernel and CLI cardLib is built on |
| 5225A "Introduction to Position Tracking" | Arc odometry |
| WPILib | Holonomic kinematics and desaturation ideas |
| Brett Beauregard, "Improving the Beginner's PID" | PID guards |
| Borenstein & Feng, UMBmark | Odometry error testing |
| Purdue SIGBots wiki | VEX sensor details |
| [doctest](https://github.com/doctest/doctest) | Laptop test framework (MIT) |

The full list, with notes on exactly what was borrowed, is in `CREDITS.md` in the repository.
